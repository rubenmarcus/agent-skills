# Reproducible handoff

Use the fields needed for the decision. Omit irrelevant ones rather than inventing values.

```text
Question or deliverable:
Owner and writable scope:
Repository / branch / revision:
Inputs and relevant configuration:
Command or observation method:

Observed result:
Artifact path or stable source:
Interpretation and uncertainty:
Independent verification status:

Next action and owner:
Stopping or reopening condition:
Last processed message ID, if using a mailbox:
```

On a conflict, compare the same input and revision before increasing experiment cost. A result with no completed measurement is unknown. A conclusion based only on a peer's summary is unverified.

Transport is optional. A built-in agent tool, shared Markdown record, append-only file queue, or an existing local service can carry the contract. Creating a custom service should solve a real session boundary, not become a prerequisite for collaboration.
