# Review output

For each actionable finding, include:

```text
Severity and short title:
Current revision or artifact identity:
Exact location:
Trigger / minimal input:
Expected versus actual behavior:
Evidence and verification status:
Impact:
Smallest sound correction:
```

Use the project's severity scale when one exists. Otherwise explain impact and likelihood directly. An unexecuted reproducer is a proposed check, not a successful reproduction.

If there are no actionable findings, state that result and the important review limits. Preserve a distinction between code inspection, executed checks, rendered inspection, and human acceptance.
