# Iteration and continuation record

```text
Objective and acceptance criteria:
Repository / branch / base revision:
Iteration and candidate revision:
Hypothesis / focused change:
Changed paths:
Verification command, exit code, and scenario:
Relevant safe diagnostic excerpt and log path:
Acceptance evidence:
Decision: keep / revise / reject / unknown
Reason:
Remaining budget, if specified:
Next concrete action:
```

Preserve this information in the project's existing handoff or results ledger. Record repeated failures and a changed hypothesis before another attempt. Missing cost instrumentation means cost is unknown, not zero.

Ralph Starter provides this class of runtime through its executor, validation, session, and circuit-breaker modules. A collection user does not need Ralph installed to follow the method. When using Ralph, inspect the installed version's help and existing configuration rather than assuming a command authorizes commit, push, or PR creation.
